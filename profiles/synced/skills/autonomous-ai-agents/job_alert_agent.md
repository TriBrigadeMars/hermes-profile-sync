# job_alert_agent

## Overview
Monitors the job feed for new remote/adjunct teaching positions and converts findings into actionable alerts — calendar events, desktop notifications, and email summaries. Acts as the bridge between the `remote_job_scout` and the user's calendar/notification system.

## Purpose
- Detect new job matches daily
- Convert each match into a calendar event (Google/Outlook/iCal)
- Send desktop notification + email digest
- Track "seen" jobs to avoid duplicate alerts

## Sources
- **Primary**: `remote_adjunct_feed.rss` (generated by `remote_job_scout`)
- **Secondary**: AcademicPositions sitemap (fallback)
- **Monitoring**: Hourly check for new items since last run

## Alerts
- **Calendar** – creates event with title, company, role, date, location
- **Desktop** – popup notification with job link and key details
- **Email** – weekly digest (handled by `remote_job_scout`)

## Schedule
- **Daily check** – hourly at 07:00 UTC (scan for new items)
- **Alert generation** – immediate upon new job detected
- **Digest** – Monday 09:00 MST (weekly summary)

## Integration
- Called by `remote_job_scout` after digest generation
- Uses `hermes calendar` and `hermes notification` tools
- Leverages `remote_adjunct_feed.rss` as the source

## Skill References
- `remote_job_scout` (job generation)
- `remote_adjunct_feed.rss` (source file)
- `hermes-agent` (core framework)
