# Resume Writing Principles

## Core goal

Produce a concise, truthful, role-relevant document that makes the candidate's strongest supported evidence easy to find and easy to parse.

## Default ordering

Use the order that best serves the target role. A common default is:

1. name/contact
2. professional summary (optional; only if it adds specific value)
3. skills/technical competencies
4. professional experience
5. selected projects or publications when relevant
6. education
7. certifications/credentials

## Bullets

Prefer bullets that communicate:

- action or responsibility;
- scope/context;
- result, effect, or purpose;
- concrete tools or methods when relevant.

A metric is useful only when known and meaningful. Never fabricate one.

Avoid empty intensifiers such as "highly," "extremely," "very," "dynamic," "results-driven," and "seasoned" unless the phrase carries specific factual content.

## Tailoring

Tailoring means selecting, ordering, and phrasing existing evidence to match the target role. It does not mean adding unsupported requirements from the posting.

Use the employer's terminology when it accurately describes the candidate's evidence. Prefer recognizable role language over idiosyncratic synonyms when truthful.

## ATS considerations

- use standard section headings;
- use clear chronology;
- avoid image-only text for critical content;
- keep contact information in ordinary text;
- do not keyword-stuff;
- do not hide keywords;
- do not claim unsupported tools merely for coverage;
- use both acronym and expanded form on first reference when useful and truthful.

No generic ATS score should be reported as if it represented an employer's actual system.
