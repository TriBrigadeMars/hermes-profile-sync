# Job Description Analysis Contract

Separate the posting into these categories:

- `must_have`: explicit required qualifications.
- `preferred`: explicitly preferred/nice-to-have qualifications.
- `responsibilities`: work the role is expected to perform.
- `domain_terms`: organization/industry terminology useful for truthful alignment.
- `tools_and_skills`: technologies, methods, credentials, and competencies named.
- `seniority_signals`: years, ownership scope, leadership expectations, decision authority.
- `performance_signals`: outcomes the employer appears to value (growth, reliability, cost, throughput, quality, compliance, etc.).
- `unknown_or_ambiguous`: language that cannot be confidently categorized.

Do not treat repeated wording as proof that a requirement is more important unless the posting's structure supports that interpretation.
