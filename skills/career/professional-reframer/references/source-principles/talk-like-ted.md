# Source Principles: Talk Like TED

Source: *Talk Like TED* by Carmine Gallo (2014).

This file contains distilled operational principles, not reproduced book text.

Applied principles:
- authentic enthusiasm and genuine expertise are more persuasive than a performed persona;
- stories make ideas and professional identity more memorable;
- conversational delivery can feel more credible than formal corporate language;
- specific, vivid examples can make abstract claims concrete;
- a central idea should organize supporting detail;
- jargon and cliches weaken memorability;
- practice and deliberate editing can make a voice sound more natural, not less authentic.

Application to professional reframing:
- preserve the user's recognizable voice;
- use concise stories in About/Experience only when they demonstrate real professional meaning;
- do not manufacture passion, vulnerability, or dramatic narrative.
