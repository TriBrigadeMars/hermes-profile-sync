# Claim Integrity

The rewriter is allowed to make the language stronger only when the underlying meaning remains equally supported.

## Claim-delta principle

Every meaningful new noun, verb, modifier, metric, and scope phrase can change the claim.

Treat the following as high-risk deltas:

- `led`, `directed`, `owned`, `managed`, `spearheaded`;
- `strategy`, `strategic advisor`, `roadmap ownership`;
- `enterprise-wide`, `organization-wide`, `global`;
- `executive`, `C-suite`, `board-facing`;
- budget or P&L responsibility;
- staff/team size;
- quantified savings, revenue, growth, efficiency, adoption, or reduction;
- `expert`, `advanced`, `specialist`, `authority`;
- causal phrases such as `resulting in`, `driving`, `delivering` when causality was not established.

## Safe vs unsafe strengthening

Usually safe when entailed:
- "showed new employees how to use software" -> "trained new employees on software use"
- "fixed user problems" -> "resolved user issues"
- "worked with finance and HR" -> "worked cross-functionally with finance and HR"

Requires evidence:
- "worked with finance and HR" -> "managed finance and HR stakeholders"
- "helped implement" -> "led implementation"
- "created reports" -> "drove executive decision-making"

## Missing metrics

Never manufacture a metric. If an outcome would benefit from measurement, ask:
- volume or frequency;
- time saved;
- error rate;
- adoption/user count;
- dollars/budget/revenue if actually known;
- cycle time;
- turnaround time;
- satisfaction or quality measure;
- before/after comparison.

If the user does not know, write a strong non-quantified statement.
