# Keyword Integration

## Purpose

Make supported professional concepts discoverable without keyword stuffing.

## Sources of target terms

In descending order of specificity:
1. target job description;
2. target title/occupation;
3. `career-market-intelligence` report;
4. industry-standard terminology;
5. the user's own preferred professional identity.

## Evidence gate

For each target term:
- **SUPPORTED:** use naturally where helpful.
- **PARTIAL/ADJACENT:** use the narrower accurate term; optionally ask for evidence.
- **UNSUPPORTED:** do not add to profile copy.

Market prevalence cannot establish candidate possession.

## Placement

High-value supported terms may appear in:
- headline;
- first part of About;
- relevant Experience entries;
- Skills section.

Do not repeat a keyword mechanically across every section.
