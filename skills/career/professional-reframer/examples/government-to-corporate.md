# Example: Government/Public-Sector to Business-Legible

## Source
"Reviewed program submissions from regional offices and sent corrections back when required fields were missing."

## Professional reframe
"Reviewed regional program submissions for completeness and compliance, resolving documentation gaps before final processing."

## Notes
`Compliance` is appropriate only if the required fields reflect an actual rule, policy, standard, or submission requirement. If they were merely formatting preferences, use `quality` or `completeness` instead.
