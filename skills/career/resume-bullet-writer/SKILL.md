# Resume Bullet Writer

Turn factual responsibilities, projects, and outcomes into concise bullets that show contribution and relevance.

Read `../_career-writing-shared/references/evidence-policy.md` and `../_career-writing-shared/references/resume-principles.md`.

## Procedure

For each evidence item:

1. Identify the candidate's actual action.
2. Identify scope/context that is explicitly supported.
3. Identify result, purpose, or downstream effect if supported.
4. Include relevant tool/method terminology only if evidenced.
5. Prefer strong accurate verbs over inflated leadership verbs.
6. Remove filler and duplicated context.
7. If a metric would materially improve the bullet but is unknown, create a follow-up question rather than a fictional number.

## Verb-strength guardrail

Do not automatically turn:
- assisted -> led;
- contributed -> owned;
- participated -> managed;
- supported -> directed;
- worked with -> partnered strategically;
- used -> expert in.

## Output

When useful, provide:
- polished bullet;
- evidence used;
- optional metric question;
- any uncertainty that should be confirmed.
