# Cross-Cutting Themes Template

Use this template to track themes across batches. Update after EACH batch.

## Template

```markdown
| Theme | Batch 1 | Batch 2 | Batch 3 | Final Insight |
|-------|---------|---------|---------|---------------|
| Theme 1 | Articles | New articles | New articles | Synthesized insight |
| Theme 2 | Articles | New articles | New articles | Synthesized insight |
```

## Example: Title IX / SA / DV Review (24 articles, 4 batches)

| Theme | Batches | Final Insight |
|-------|---------|---------------|
| Gap between policy intent and implementation | All 4 batches | Central paradox: more legislation than ever, but rates haven't declined |
| Knowledge-behavior gap | Batches 2-4 | Programs change knowledge (ES=.513) but NOT bystander behavior (ES=.075) |
| Inadequate resources / unfunded mandates | Batches 2-4 | Campus SaVE Act mandates programming but provides no funding |
| Failure to center marginalized voices | Batches 1, 3, 4 | Programs least effective for those at highest risk (disabled, LGBTQ+, minority) |
| Organizational culture resistance | Batches 1-3 | Institutions frame harassment as individual problem, not systemic |
| Intersectionality as framework | Batches 3-4 | Multiple marginalized identities compound risk; programs must address this |
| Economic supports as violence prevention | Batch 4 | Financial stability is protective; MFIP reduced IPV from 60% to 49% |
| Bystander intervention — effective but limited | Batch 4 | Knowledge/intentions improve; actual behaviors don't change |
```

## Naming Conventions

- Theme names should be short noun phrases (5-10 words)
- "Refined Insight" should be a single sentence (not a paragraph)
- Mark themes as "NEW" when they first appear
- Merge themes when they overlap (don't keep two themes saying the same thing)
