# Stage 4 — Quality Assessment and Bias Framework

## Overview
Quality assessment for this scoping review uses a dual-framework approach adapted for harassment/discrimination research:
1. **JBI Critical Appraisal Checklist** (adapted by study design)
2. **MMAT (Mixed Methods Appraisal Tool)** for mixed-methods studies
3. **Discrimination-Specific Quality Domains** (custom)

## 3. Discrimination-Specific Quality Domains (Custom)

### 3.1 Minority Representation Quality

| # | Domain | Rating | Notes |
|---|--------|--------|-------|
| D1 | **Adequate minority sample size**: Minority subgroup sample ≥ 100 for quantitative; ≥ 15 for qualitative | | |
| D2 | **Disaggregated analysis**: Results reported separately for minority subgroups (not collapsed into single "minority" category) | | |
| D3 | **Intersectional analysis**: Study examines ≥ 2 identity dimensions simultaneously (e.g., race × gender) | | |
| D4 | **Diverse recruitment**: Sample includes multiple minority groups, not single-group convenience | | |
| D5 | **Minority-specific instruments**: Measures validated for or adapted to minority populations | | |

### 3.2 Harassment/Discrimination Measurement Quality

| # | Domain | Rating | Notes |
|---|--------|--------|-------|
| H1 | **Validated exposure measure**: Uses psychometrically validated instrument (e.g., SEQ, SES, Experiences of Discrimination Scale) | | |
| H2 | **Comprehensive harassment types**: Captures multiple forms (verbal, physical, quid pro quo, hostile environment) | | |
| H3 | **Contextual detail**: Reports campus location, perpetrator identity, institutional response | | |
| H4 | **Intersectional exposure**: Measures harassment/discrimination targeting multiple identities | | |
| H5 | **Temporal specificity**: Reports when harassment occurred (enrollment period) and frequency | | |
| H6 | **Reporting behavior**: Examines formal/informal reporting and reasons for non-reporting | | |

### 3.3 Institutional Context Quality

| # | Domain | Rating | Notes |
|---|--------|--------|-------|
| I1 | **Title IX policy context**: Describes institutional Title IX policies/procedures | | |
| I2 | **Campus climate data**: Includes institutional campus climate measures | | |
| I3 | **Institutional diversity**: Describes institutional demographics and diversity infrastructure | | |
| I4 | **Institutional response**: Examines how institutions respond to reports | | |
| I5 | **Policy changes**: Accounts for policy changes during study period (e.g., 2020 Title IX rules) | | |

### 3.4 Methodological Rigor for Vulnerable Populations

| # | Domain | Rating | Notes |
|---|--------|--------|-------|

## 4. Overall Quality Rating

### Rating Scale
Each study receives an overall quality rating based on the applicable JBI/MMAT checklist and discrimination-specific domains:

| Rating | Description | Criteria |
|--------|-------------|----------|
| **HIGH** | Strong methodology, minimal bias risk | JBI ≥ 80% "Yes"; all discrimination domains ≥ "Adequate" |
| **MODERATE** | Adequate methodology, some limitations | JBI 60-79% "Yes"; most discrimination domains ≥ "Adequate" |
| **LOW** | Significant methodological concerns | JBI < 60% "Yes" OR critical discrimination domains rated "Inadequate" |

### Critical Quality Thresholds
Studies automatically rated LOW if:
- Minority sample size < 30 for quantitative analysis
- No validated exposure measure used
- No disaggregated results for minority subgroups
- No ethical approval documented
