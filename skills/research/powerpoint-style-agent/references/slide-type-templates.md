# Slide Type Templates

## 1. Content Slide
```
[Bold Header - fragment]

• Bullet point 1
• Bullet point 2
• Bullet point 3
```

## 2. Audience Poll Slide
```
[Centered question]

"When you hear the phrase
'[topic]', what comes to mind?"
```

## 3. Myth/Fact Slide
```
Myth:
[Common misconception]

Fact:
[Correction with explanation]
```

## 4. Framework Slide (2x2)
```
[Framework Name]

[Option A]        [Option B]
[Option C]        [Option D]
```

## 5. Scenario Slide
```
[Scenario Title]

[Plain-language description of situation]

Discussion Prompts:
1. [Prompt 1]
2. [Prompt 2]
3. [Prompt 3]
```

## 6. Resource Directory Slide
```
[Office/Resource Name]

[What they do - 1-2 lines]

Contact:
Email: [email]
Phone: [phone]
Website: [url]
```

## 7. Process/Flowchart Slide
```
[Process Name]

Step 1 → Step 2 → Step 3
         ↓
    [Decision Point]
    ↓           ↓
  [Yes]       [No]
```

## 8. Reflection Slide
```
What is A Change You Hope To
Take Away or See from This Training?

1. [Sub-prompt 1]
2. [Sub-prompt 2]

(Suggestion, not a request: [guidance])
```

## 9. Break Slide
```
Let's take a quick break!
However that may look like for you whether that is:

1. Eating a quick snack
2. Drinking a glass of water
3. Using the restroom
4. Relaxing back, neck, or shoulder muscles
```

## 10. Disclaimer Slide
```
Disclaimers

1. [Disclaimer 1]
2. [Disclaimer 2]
3. [Disclaimer 3]
```
